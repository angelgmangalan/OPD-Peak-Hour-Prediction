# OPD-Peak-Hour-Prediction
Healthcare project for analysing and forecasting hourly hospital OPD patient demand.

## Project Overview

This project focuses on predicting peak consultation hours in Hospital Outpatient Departments (OPDs) using historical appointment data.

The project aims to:
- Analyse historical OPD patient arrivals.
- Forecast hourly patient demand.
- Generate prediction intervals to represent uncertainty.
- Classify hourly demand into Low, Normal and High.
- Develop a dashboard to display patient demand and peak-hour warnings.

## Dataset

The project uses historical Hospital OPD appointment data.

The data is processed to create hourly and daily patient arrival counts.

Note: Only approved, anonymized and aggregated data should be shared in this repository. No identifiable patient information is included.
